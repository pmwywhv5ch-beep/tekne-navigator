TEKNE NAVIGATOR - iPHONE KURULUM

1) Bu klasördeki TÜM dosyaları GitHub repository'sine yükle:
   index.html
   waypoints.json
   manifest.json
   sw.js
   icon-192.png
   icon-512.png

2) GitHub Pages'i aç:
   Settings > Pages
   Deploy from a branch
   main / root
   Save

3) Oluşan https://KULLANICI.github.io/REPO/ adresini iPhone Safari'de aç.

4) Safari > Paylaş > Ana Ekrana Ekle.
   Web App seçeneğini açık bırak.

Not:
- Uygulamanın kendi verileri localStorage ile telefonda tutulur.
- Harita, hava ve batimetri gibi dış servisler internet bağlantısı gerektirebilir.
- Service Worker uygulama kabuğunu ve yerel dosyaları önbelleğe alır.
